# LAITYS WB Study

Кабинет продавца Wildberries на Python и FastAPI: сводка продаж, поиск товаров, учёт расходов и экспорт в CSV.

Приложение использует вымышленные данные за **1–14 октября 2026 года**. Подключение к API Wildberries не требуется.

Адреса, порт, хранение данных и команды управления собраны в [паспорте проекта](project_passport.md).

## Установка

Нужны Python 3.11+ и Git. Выполните:

```bash
git clone https://github.com/yaroS1AVE/laitys-wb-study.git
cd laitys-wb-study
python -m venv .venv
```

Активируйте окружение:

- Windows PowerShell: `.\.venv\Scripts\Activate.ps1`
- Linux / macOS: `source .venv/bin/activate`

Установите зависимости приложения и тестов:

```bash
python -m pip install -r requirements-dev.txt
```

Если PowerShell запрещает активацию, используйте `.\.venv\Scripts\python.exe` вместо `python` в командах установки, запуска и тестирования. В Linux / macOS при необходимости используйте `python3` для создания окружения.

## Запуск

```bash
python -m uvicorn app_final:app --host 127.0.0.1 --port 8000
```

- [Кабинет](http://127.0.0.1:8000/)
- [Документация API](http://127.0.0.1:8000/docs)
- [Работоспособность сервиса и хранилища](http://127.0.0.1:8000/health)
- [Версия приложения](http://127.0.0.1:8000/version)

В Windows также доступен `Запустить.cmd`: при первом запуске он создаёт окружение и устанавливает зависимости. Остановка сервера — **Ctrl+C**.

## Тесты

```bash
python -m pytest -v
```

Тесты проверяют API, поиск, параметры, расчёт прибыли и сохранение расходов. Для каждого теста используется отдельное временное хранилище.

## Настройки

При необходимости скопируйте `.env.example` в `.env`. Переменные окружения имеют приоритет над `.env`; после изменения настроек перезапустите сервер.

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `LAITYS_SHOP_NAME` | Название магазина | `LAITYS · учебный магазин` |
| `LAITYS_LOG_LEVEL` | Уровень логов | `INFO` |
| `LAITYS_DATA_DIR` | Папка сохраняемых расходов относительно проекта | `.runtime` |

Товары и продажи находятся в `data/demo.json`, изменяемые расходы — в `.runtime/expenses.json`. Файлы `.env` и `.runtime/` исключены из Git.

## Основные маршруты

| Маршрут | Назначение |
|---|---|
| `GET /api/products?q=лампа` | Каталог и поиск по названию или артикулу |
| `GET /api/products/{sku}` | Карточка товара |
| `GET /api/report?date_from=2026-10-01&date_to=2026-10-14` | Сводка за период |
| `GET /api/expenses`, `POST /api/expenses` | Просмотр и добавление расходов |
| `DELETE /api/expenses/{id}` | Удаление расхода |
| `GET /api/export` | CSV; поддерживает `date_from` и `date_to` |

Прибыль = выручка − комиссия − логистика − себестоимость − дополнительные расходы. В примере комиссия составляет 20%, логистика — 35 ₽ за единицу. Это условные значения. Прибыль товаров показана до общих расходов, в сводке они вычитаются один раз.

## Диагностика

Логи находятся в терминале запуска: начало и завершение работы, HTTP-запросы, коды ответов, время обработки и операции с расходами.

Для проверки откройте `/health` и `/version` по ссылкам выше. Исправный сервис возвращает в `/health` статус `ok`; `/version` содержит версию приложения.

- Нет модуля `fastapi` или `uvicorn` — проверьте окружение и установите зависимости.
- Порт занят — остановите другой сервер или укажите `--port 8001`.
- Сводка пустая — выберите период 1–14 октября 2026 года.
- Ответ `503` — проверьте права записи в `LAITYS_DATA_DIR` и формат файла расходов; подробности смотрите в терминале.
